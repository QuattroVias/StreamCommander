## 📌 Что это?

**Stream Commander** — это мощный инструмент для стримеров, который автоматизирует взаимодействие с чатом, обработку донатов, заказов видео и интеграцию с OBS. Он делает эфиры динамичными, интерактивными и удобными.

## ✨ Основные возможности

| Функция                                    | Что умеет                                                                                                   |
|--------------------------------------------|-------------------------------------------------------------------------------------------------------------------|
| 🔊 **Озвучка чата и событий**  | Автоматически озвучивает сообщения чата VK и Twitch<br>Озвучивает донаты, награды, системные уведомления<br>Кастомные голоса, скорость речи, свои фразы<br>Конвертация валют в донатах для правильных сумм  |
| 🎬 **Заказы видео и клипов**     | Принимает заказы с YouTube (по ссылке или по названию)<br>Принимает заказы с VK Video (по ссылке)<br>Фильтры по длительности и количеству просмотров<br>Общая очередь с приоритетами и возможностью «вне очереди»<br>Кэширование видео и кастомные плейлисты |
| 💸 **DonationAlerts**          | Мгновенный мониторинг виджета в реальном времени<br>Автоматическая конвертация USD, EUR, KZT и других валют в RUB<br>Реакции на донаты: озвучка, сообщения в чат, скрипты OBS |
| 🏆 **Наград и событий**        | Реакции на подписки, рейды, фолловы, реварды, порталы<br>Скрипты: озвучка, сообщения и все функции скриптом для OBS |
| 👥 **Мониторинг зрителей**     | Сбор списка активных зрителей с Twitch и VK Live<br>Уведомления о появлении особых пользователей (опции)<br>Фильтры чата: по длине сообщения, таймауты, лимиты |
| 🎮 **Интеграция с OBS**        | Управление сценами, источниками и фильтрами через WebSocket<br>Мониторинг времени стрима, дропов кадров, переподключений<br>Уведомления о проблемах в чат и через TTS |
| ⚙️ **Скрипты**                 | Создание полностью кастомных скриптов на любые события<br>Переключение фильтров, громкости, источников и сцен<br>Задержки, комбинации, очередность|
| ⌨️ **Горячие клавиши**         | Быстрое управление во время стрима:<br>Пауза/пропуск клипа ∙ вкл/выкл TTS ∙ регулировка громкости<br>Обновление источников ∙ показ очереди ∙ повторная озвучка ∙ и т.д.   |
| 📊 **Отчёты и аналитика**      | Сохранение всех данных: зрители, донаты, награды<br>Удобные фильтры по дате и платформе |
